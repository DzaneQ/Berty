# Field

Field is an object to put a board card on. Fields contain information about what cards are on them and their alignment. Each field can have max 1 card with an exception of TrenerPokebertow whose ability allows to hold 2 cards. They must contain the alignment of one of the players when they have a card or the alignment of none if there are no cards on them.

# Colorizing and highlighting

The field's color determines who owns the card on it.

Highlights allow the player to see which fields are under attack depending on which card is hovered on.
